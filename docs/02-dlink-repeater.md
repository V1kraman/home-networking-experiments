# D-Link DIR-615 Wireless Repeater

## Objective

Extend Wi-Fi coverage wirelessly.

---

## Configuration

Configured the D-Link DIR-615 as a wireless repeater.

Result:

Successful.

---

## Performance

Advantages

- Extended coverage
- Simple setup

Limitations

- 2.4 GHz only
- Wi-Fi N
- 150 Mbps link rate
- Single-radio repeating

The repeated network was functional but significantly slower than the primary network.

---

## Conclusion

Although technically successful, hardware limitations made this unsuitable for modern high-speed internet usage.
